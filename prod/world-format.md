# World format

A world is one world.yaml with `format: 1`, `meta`, and the keyed sections below. Every section maps a snake_case name to an item. Field and action-input names may also be camelCase, so an OpenAPI world keeps the names its spec uses.

## meta

- `name` (string matching `^[a-z][a-z0-9_]*$`, required): snake_case identifier
- `description` (string, required)
- `resembles` (string, required): the real software this world mirrors, such as "Zendesk tickets API"
- `source` ("hand" | "worldgen", required)
- `seed` (integer, required): rng seed for seed snippets
- `clock` (object, required)
  - `start` (date-time string, required)
  - `tick` (string, optional, default "0s"): engine time added after each committed call. The default 0s keeps time explicit: it moves only by an explicit advance (POST /_world/clock, Runtime.advance) or an action duration. Set it, such as 1s, to opt in to per-call drift.
- `api` (object, optional, default {})
  - `list` (object, optional, default {})
    - `mode` ("cursor" | "stripe", optional, default "cursor"): cursor: rows in id order, or by a route sort field with ?sort=field or ?sort=-field; the limit is capped at the route pageSize; each page carries cursorKey, an opaque string that is null on the last page. stripe: Stripe list paging. Rows are newest first by created_at, ties by id descending; ?sort is refused. The limit is 1 to 100 and defaults to the route pageSize capped at 100. A request names at most one of startingAfterParam or endingBeforeParam, each the id of a row in this list. The page carries the boolean hasMoreKey instead of a cursor. Example: with three charges and {"mode":"stripe"}, GET /v1/charges?limit=2 returns ch_0003 and ch_0002 with has_more true, ?limit=2&starting_after=ch_0002 returns ch_0001 with has_more false, and ?ending_before=ch_0001 returns ch_0003 and ch_0002 with has_more false.
    - `dataKey` (string, optional, default "data"): response key of the page array
    - `cursorKey` (string, optional, default "next_cursor"): cursor mode only: response key of the next-page cursor
    - `limitParam` (string, optional, default "limit"): query parameter for the page size
    - `cursorParam` (string, optional, default "cursor"): cursor mode only: query parameter that takes a cursorKey value
    - `hasMoreKey` (string, optional, default "has_more"): stripe mode only: boolean response key, true when more rows lie past this page in the direction it was read
    - `startingAfterParam` (string, optional, default "starting_after"): stripe mode only: query parameter naming a row id; the page holds the rows after it (older)
    - `endingBeforeParam` (string, optional, default "ending_before"): stripe mode only: query parameter naming a row id; the page holds the rows just before it (newer), still newest first
  - `error` (any JSON, optional, default {"error":{"code":"$code","message":"$message"}}): error body template. $status, $code, $message, $type and $param are replaced. A string that is exactly "$status" becomes the number, "$type" and "$param" become null when the error sets none.

## tasks

Each item:

- `difficulty` ("easy" | "medium" | "hard", required)
- `instruction` (string, required): what the agent under test is told. Do not leak ids it should discover.
- `grader` (string, optional): present in the private world; a public bundle drops it and keeps only the instruction (YOS-159)
- `solution` (string, optional): present in the private world; a public bundle drops it and keeps only the instruction (YOS-159)
- `decoys` (list of object, optional, default []): wrong solutions that must score below 1. Required on medium and hard.

  - `script` (snippet (client), required): See Snippets, client.
- `alternatives` (list of object, optional, default []): other correct solutions that must score exactly 1, so the grader judges the outcome, not one path (A-199)

  - `script` (snippet (client), required): See Snippets, client.
- `allows` (list of object, optional): the changes the task permits, from its instruction, not from what the solution happens to write. A task without it is a legacy task, judged by its grader's own guards and the engine mutants (YOS-156).

  - `kind` ("created" | "updated" | "deleted", required)
  - `fields` (list of string matching `^[a-z][a-zA-Z0-9_]*$`, optional, default []): for updated: the only fields a change may touch. Ignored for created and deleted.
  - `where` (map of name to string | number | boolean | null, optional): only rows with these field values: seed values for updated and deleted rows, end values for created ones. Omit to allow every row of the entity.

## Snippets

Snippet fields hold a JS function as a string. What each kind receives:

### handler

```text
JS function (ctx) => ... returning { status, body }. Synchronous. No Date, Math.random, timers or imports.
ctx.params: Record<string, string>. Path parameters, such as id in /tickets/{id}.
ctx.query: Record<string, string>. Query string parameters.
ctx.body: Record<string, unknown>. Request body, already validated against the action input.
ctx.db: get(entity, id) => Row | null; list(entity, { where? }) => Row[]; create(entity, data) => Row; update(entity, id, patch) => Row; delete(entity, id). Every write enforces the data model. Any throw rolls back the whole call.
ctx.now: () => string. Engine time as ISO 8601. Never use Date.
ctx.time: plus(iso, "15m") => iso; minus(iso, "3d") => iso; minutesBetween(a, b) => number. Pure date math on ISO strings. The offset is unsigned and may be zero, such as "0d", "45m" or "1d12h": plus moves later, minus moves earlier ("3d ago"). A signed offset such as "-5d" throws: use minus.
ctx.fail: (status: 400 | 404 | 409 | 422, code, message, extra?: { type?: string; param?: string }) => never. Abort the call. Nothing is written. The optional extra fills $type and $param in the world error template.
```

### grader

```text
JS function (ctx) => ... returning a number in [0, 1], such as ctx.score(). It must return 0 on the untouched seed.. Synchronous. No Date, Math.random, timers or imports.
ctx.db: get(entity, id) => Row | null; list(entity, { where? }) => Row[]. End state, read-only.
```

## WorldEdit
