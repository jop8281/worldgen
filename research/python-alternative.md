# Python alternative (considered, not chosen)

The user chose TypeScript on 2026-10-06 because a factory session had already built about 4k lines of the TypeScript design. This file keeps the measured Python replan so the choice is auditable. Python's main gap, running model-written logic deterministically, was closed by a whitelisted-AST subset prototype (blocked 13 of 13 escape probes, identical output across hash seeds, 3.2 us per call). Starlark via starlark-pyo3 was the slower fallback. SQLite :memory: forks via the backup API cost 65 us.
