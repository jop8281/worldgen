**Status rules.** *Met* means the whole requirement holds and someone read the cited code or ran the cited command and saw the result. *Partial* means part holds, or the claim appears only in docs, plans or PR text, or a gate exists but does not block. *Open* means not built. Each *Met* row was reopened by a second reviewer who tried to refute it. Requirement ids are ours: E is the world engine, W is WorldGen outputs and inputs, S is stage, M is a WorldGen minimum feature, G is a good-world property and D is a deliverable. Where the spec is ambiguous, the call is a `Spec:` row in `decisions.md`.

**Rechecking.** Run a cited command from `code/` under `nice -n 15`. A bare `file.ts:line` names the one file with that name under `code/src/`. Where two share a name (store.ts, sandbox.ts), it is the one under `code/src/engine/`. Every cited line number was checked to exist in the file when this was written, and the line text was read by the reviewers. In the 2026-10-07 audit a script moved each cited range to where the text it named at the time now sits, and flagged each range whose text had changed or did not contain the identifier written beside it. Each flagged range was read and fixed by hand, and each cited test file was rerun.
