## 6. Findings outside the cleanup scope

These came up during the inventory and are reported here. Each needs its own issue, not a cleanup PR.

1. **eval ignores `config.transport`.** `code/src/cli/eval.ts` (about line 98) hard-defaults the transport to `claude-cli`, while every other CLI uses `transportOf(config)`. This is a behaviour defect, owned by YOS-203 or a new defect issue.
2. **AGENTS.md's path claim is only partly enforced.** AGENTS.md says `test/architecture.test.ts` checks that every path AGENTS.md names exists. What it checks is the reverse: that AGENTS.md names every `src` module ('AGENTS.md names every src module'). `test/docs.test.ts` R17 checks that documented scripts and commands exist. Nothing fails on a dangling backticked path. A manual check at `cf60b9fb` found every backticked path resolves, generated outputs aside. Owner: YOS-201, to add the check or correct the sentence.
3. **No decision row retires the Airflow factory.** A-186 is its only row, so removing `factory.toml` and `scripts/factory-check.sh` needs a superseding row, with an A-number from the master.
4. **Red-team probes skip silently.** The 'unit not landed' capability probe in `code/test/redteam/harness.ts` still gates every row, and CI does not set `REDTEAM_STRICT`, so a capability that regressed would be skipped without a failure. Owner: YOS-205.
5. **`code/scripts/` is outside the `tsconfig` include,** so none of the `harden-*`, `tune-*` or `set-*-clock` scripts is typechecked. Owner: YOS-210.
6. **`.gitignore` lacks `.env.*`, `*.pem` and `*.key`,** which `.dockerignore` excludes. Owner: YOS-208.
