# Spec calls: engine-format

- `emptyWorld` meta defaults are `description: ''`, `resembles: ''`, `seed: 0`, `clock.start: '2026-01-05T09:00:00.000Z'` and the schema default tick `1s`. Why: the issue fixes only the start, and empty strings pass the schema so the meta stage fills them in later. Reversible: yes.
- `emptyWorld` returns `worldSchema.parse(...)`, so it throws on a `name` that is not a snake_case `Name`. Why: a world that fails its own schema must never be a starting point. Reversible: yes.
- `editJsonSchema` keeps `note` and `meta` and narrows only `upsert`, `patch` and `remove`, in `SECTIONS` order whatever order `writes` comes in. It is emitted with `io: 'input'`, so fields with defaults are optional for the model. Why: `meta` is not a `Section`, a stable key order keeps prompts byte-identical, and the model writes input, not parsed output. Reversible: yes.
- `fromZod(error, base, { schema, input })` takes the parsed schema and value as a required third argument, so the type sketch's two-argument call no longer compiles. Why: zod v4 issues carry neither the schema (for `.describe()` hints) nor the input (unless `reportInput`), and an optional argument let callers silently lose `found` and the hint. `issue.input` wins over walking `input`. Reversible: yes.
- For a bad record key (zod `invalid_key`), `found` is the key as JSON, `expected` is the zod message plus the key schema's messages, and the hint uses the record key schema's `.describe()` text (for `Name`, `snake_case identifier`). Why: walking the path finds the whole item and the value schema, which hides the most common model mistake (camelCase names). Reversible: yes.
- `fromZod` accepts an empty `base` for a whole-world parse. A result path that is still empty (the input is not an object) becomes `['format']`. A non-zod error becomes one `schema.invalid` issue at `base`. Why: `IssuePath` needs a head and `NonEmpty` needs one issue. Reversible: yes.
- `found` is the value as JSON, cut to 200 chars as the first 197 plus `...`. An absent value is `missing`, and `unknown` only for a non-zod error. Why: the issue asks for JSON truncated to 200 chars and does not say how to render an absent value. Reversible: yes.
- The `schema.invalid` hint becomes `<describe text>. Match the shape in prod/world-format.md.` when the field has `.describe()` text, and keeps the old text otherwise. `describe` is a new optional catalog param. Why: acceptance 4 puts the describe text in the hint, and the catalog is the only place hints live (A-25). Reversible: yes.
- `formatReference` renders from `z.toJSONSchema` of each schema with `io: 'input'`. A snippet field shows `snippet (<kind>)`, and each `snippetDoc(kind)` appears once under `## Snippets`. Why: the full ctx doc on every snippet field would repeat each kind several times. Reversible: yes.
